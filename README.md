# SudKZ — линия релизов для МФО Алматы

Здесь публикуются **только обновления** сборки SudKZ для МФО Алматы.

| Что | Где |
|---|---|
| `version.json` | какая версия сейчас актуальна — по нему приложение проверяет обновления |
| Установщики `SudKZ-Setup-*.exe` | во вкладке **Releases** |

**Исходного кода здесь нет.** Он в закрытом репозитории.

**Персональных данных здесь нет и быть не может.** Логи и трекеры подач содержат ИИН, ФИО
и номера дел должников — они выгружаются исключительно в приватные репозитории.

## Как выпустить новую версию

1. `py tools\release\bump_version.py X.Y.Z` в репозитории кода
2. `build\СОБРАТЬ.bat` — собрать установщик
3. создать здесь Release `vX.Y.Z` и приложить `SudKZ-Setup-X.Y.Z.exe`
4. запушить сюда обновлённый `version.json`

После этого приложение у клиента увидит обновление кнопкой «Проверить обновление».
